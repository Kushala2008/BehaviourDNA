# BehaviourDNA
An AI-powered project exploring behavioural patterns and personalised insights
BehaviourDNA

A valid login is not the whole story.

Problem Statement

Traditional authentication systems mainly verify a user's identity at login. However, a valid login alone may not guarantee that the account is being used by its legitimate owner throughout the session.

Proposed Solution

BehaviourDNA aims to explore behavioural-based continuous authentication. It analyses patterns in user interactions to identify unusual behaviour and help detect potentially unauthorised account usage.

Key Objectives

- Go beyond traditional login-based authentication.
- Study behavioural patterns during user sessions.
- Identify unusual interaction patterns.
- Provide alerts when suspicious activity is detected.
- Explore privacy-conscious security approaches.
